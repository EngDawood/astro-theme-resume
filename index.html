PROJECT / 04

Video Caption Bot

Send a video or a social link to this Telegram bot and it transcribes the speech, translates it, and burns the captions back into the video. It runs as a durable pipeline on Cloudflare Workflows, so each stage retries on its own, and ffmpeg runs in Cloudflare Containers. Finished jobs can be re-run at four depths, from full redo to restyle only.

  • سلّمت مشاريع تطوير ويب متكاملة وأتمتة بايثون وتوثيقًا تقنيًا لعملاء دوليين.

الأنظمة الخلفية والبنية التحتيةNode.js, Hono, grammY، بايثون، Cloudflare Workers (D1, KV, R2, Queues, Durable Objects, Workflows, Containers)، تصميم REST API، Webhooks، Cron، Telegram Bot API.
قواعد البياناتSQLite / Cloudflare D1, MySQL, PostgreSQL، تحسين استعلامات SQL، تصميم المخطط، Redis (أساسيات).
DevOps والأدواتGit, GitHub Actions، التكامل والنشر المستمر، النشر على npm، Wrangler, Docker (أساسيات), Linux CLI؛ LaTeX, MS Office, Canva, Prezi.
المعماريةClean Architecture، مبادئ SOLID، أنماط التصميم (Repository, Factory, Observer)، تعدد المستأجرين في SaaS، الميكروسيرفس (دراسة)، اختبار الوحدات.
